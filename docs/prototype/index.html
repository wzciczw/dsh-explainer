LayerFS 里一个 Branch 的成本到底高不高？我想知道 fork 和 merge 各自贵在哪。

D
DeepSeek Harness

先把结论说在前面：创建分支几乎不花钱，贵的是合并。

  • fork 只是把当前提交的引用复制一份，不复制文件内容，所以是常数级开销。
  • 每个 Commit 记录的是相对父提交的增量，多个分支各自长，互不影响。
  • 真正开始花钱是在 merge：需要找出共同祖先，做三方合并，冲突时还要人来看。

所以“多开分支”这个动作本身不该被优化，应该优化的是让分支尽快汇合，减少长期分叉。
